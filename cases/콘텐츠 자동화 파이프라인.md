# 콘텐츠 자동화 파이프라인

커뮤니티 게시글을 수집하고 이미지·텍스트를 분석해 숏폼 콘텐츠를 생성, 렌더링, 업로드하는 프로젝트에서 발견한 문제를 기록한다.

## 시스템 개요

추후 실제 구조를 기준으로 작성한다.

## 연결된 개념

개념을 공부하거나 설계 문제를 분석할 때 관계와 함께 추가한다.

## 사례

아직 기록된 사례가 없다. 새 사례는 [[Project Case Template]]을 사용한다.

## 미해결 질문

- 파이프라인 단계별 실패와 재시도는 어떻게 처리했는가?
- 동일한 콘텐츠의 중복 처리와 업로드를 어떻게 방지했는가?
- 긴 작업의 상태와 진행률을 어떻게 저장했는가?
