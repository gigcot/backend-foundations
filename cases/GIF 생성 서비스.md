# GIF 생성 서비스

GIF와 이미지를 입력받아 개별 프레임을 합성하고 새로운 GIF를 만드는 서비스의 운영·설계 문제를 기록한다.

## 시스템 개요

추후 실제 구조를 기준으로 작성한다.

## 연결된 개념

개념을 공부하거나 설계 문제를 분석할 때 관계와 함께 추가한다.

## 사례

아직 기록된 사례가 없다. 새 사례는 [[Project Case Template]]을 사용한다.

## 미해결 질문

- 동일한 생성 요청이 중복 실행될 가능성이 있는가?
- 외부 API의 지연과 실패를 어떻게 처리하는가?
- 이미지 처리 작업이 서버 자원에 주는 영향을 어떻게 측정하는가?
- 작업 상태와 결과 파일의 수명 주기를 어떻게 관리하는가?
