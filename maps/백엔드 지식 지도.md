# 백엔드 지식 지도

이 저장소의 최상위 MOC다. 개별 기술 이름보다 백엔드가 해결해야 하는 문제를 중심으로 지식을 연결한다.

노트를 새로 만들거나 합치고 나누는 기준은 [[Knowledge Base 운영 지침]]을 따른다.

## 핵심 지도

- [[데이터베이스 MOC]] — 데이터를 정확하고 효율적으로 저장하고 변경하기
- [[네트워크와 웹 MOC]] — 요청과 응답이 전달되는 과정 이해하기
- [[운영체제와 동시성 MOC]] — 프로그램 실행과 자원 경쟁 이해하기
- [[Python 백엔드 MOC]] — Python 서버의 실제 실행 모델 이해하기
- [[분산 시스템 MOC]] — 여러 프로세스와 서비스 사이의 실패 다루기
- [[관측성과 성능 MOC]] — 시스템 상태를 측정하고 병목을 찾기
- [[보안 MOC]] — 신뢰 경계를 정하고 공격 가능성 줄이기
- [[자료구조와 알고리즘 MOC]] — 문제 해결 비용과 선택 근거 이해하기

## 현재 학습 경로

1. 첫 질문을 [[Inbox]]에서 선택한다.
2. 관련 MOC에서 선행 개념을 확인한다.
3. 개념 노트와 필요한 실험을 만든다.
4. 프로젝트 사례에 적용하고 복습한다.

## 연결되지 않은 노트

새 노트가 생겼지만 아직 적절한 MOC나 관련 노트와 연결하지 못했다면 여기에 임시로 둔다.
